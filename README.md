The ‘Ancestral Reconstruction’ skill in OpenClaw was developed through training on the Xiaomi Mimo V2 Pro. This skill allows you to upload your amino acid sequence, automatically download the corresponding genomic files from NCBI, construct a phylogenetic tree of orthologs using OrthoFinder, and perform ancestral reconstruction via PAML using the resulting phylogenetic tree.
The amino acid format for input to OpenClaw is as follows:

‘>Species name 1‘

’Amino acid sequence’

‘>Species name 2’

‘Amino acid sequence’

‘......’
